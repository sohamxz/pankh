# Design Specification: `llms.txt` & `llms-full.txt` AI Documentation Generator

## Summary
Implement an AI documentation generator (`src/core/llmstxt.rs`) that parses project Markdown files and builds standardized `llms.txt` (H1/H2 structural index) and `llms-full.txt` (bundled token-thrifty AST-cleaned document payload) according to the `llms.txt` spec.

---

## 1. Specification & Output Format

### Output Files
1. **`llms.txt`**:
   ```markdown
   # <Project Title / Folder Name>

   > Generated by Pankh (🪶) AI Documentation Engine.

   ## Summary & Outline Index
   - [README.md](file:///path/to/README.md): H1: Overview (Tokens: 450)
     - H2: Installation
     - H2: Usage
   - [docs/arch.md](file:///path/to/docs/arch.md): H1: Architecture (Tokens: 820)
   ```

2. **`llms-full.txt`**:
   Contains the concatenated AST-cleaned text of all `.md` files in the project, separated by `\n\n---\n\n` dividers, stripped of badges, frontmatter, tracking parameters, raw SVGs, and HTML comments.

---

## 2. Component Architecture

### Data Structures (`src/core/llmstxt.rs`)

```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct LlmsTxtOutput {
    pub index_content: String,
    pub full_content: String,
    pub files_processed: usize,
    pub total_raw_tokens: usize,
    pub total_clean_tokens: usize,
    pub tokens_saved: usize,
}

pub fn generate_llmstxt(paths: &[PathBuf]) -> LlmsTxtOutput;
```

### CLI Flag Integration (`src/main.rs`)
- `--llms-txt`: Triggers `generate_llmstxt` on input file/directory arguments (defaults to current directory `.`).
- Outputs `llms.txt` and `llms-full.txt` files to disk (or prints JSON when `--json` is supplied).

## 3. Verification Plan

### Automated Unit & Integration Tests
- `test_generate_llmstxt_index_and_full`: Verifies that `index_content` contains heading references and `full_content` contains AST-cleaned body text without badge images.
- `test_cli_llmstxt_flag`: Verifies `pankh --llms-txt` CLI output.
